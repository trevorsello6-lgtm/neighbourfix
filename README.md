# NeighbourFix MVP

A small, mobile-friendly, South Africa-focused local-services marketplace prototype. This is a static front-end MVP designed to validate interest before investing in an app or backend.

## Run it

- Open `index.html` directly in a modern browser, or serve this folder with any static web server.
- No build step, framework, account, API key, or backend is required.
- On GitHub, use **Settings → Pages** and publish the `build/neighbourfix-mvp` branch from `/ (root)` to host the demo.

## Prototype functionality

- Service-category cards preselect the booking form.
- Customer request form with basic required-field validation and consent checkbox.
- Provider interest form.
- Demo dashboard with request/provider counts and status updates.
- CSV export and clear-local-demo-data controls.
- Responsive mobile layout, privacy notice and prototype terms.

## Important limitations

Submissions are stored only in the browser's `localStorage`. They are not sent to the owner, a server, or a provider; there is no authentication, secure database, real booking workflow, matching, payment, messaging, verification, or email notification. Anyone using the same browser profile can access this demo data. The dashboard is not private or secure. Do not collect real personal or sensitive information with this prototype.

Before a real launch, add a secure backend and authenticated admin access; set up monitored contact details and email/SMS/WhatsApp operations; implement consent, retention, deletion and security controls; and have South African privacy, consumer, tax, employment/contractor, payment and marketplace terms reviewed for the actual business model. The included legal copy is clearly marked as prototype-only and is not legal advice.
